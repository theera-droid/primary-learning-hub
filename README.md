# ห้องเรียนคอมจิ๋ว

คลังบทเรียน ป.4–ป.6 พร้อมสไลด์ ใบงานสี/ขาวดำ แผนการสอน และคำอธิบาย/โครงสร้างรายวิชา

เว็บไซต์เป็นเวอร์ชันสำหรับผู้เรียนและผู้เยี่ยมชม ไม่ใช้ฐานข้อมูลหรือระบบเข้าสู่ระบบของเครื่องครู

## เปิด GitHub Pages

Settings → Pages → Deploy from a branch → main → /docs → Save

เปิดหน้าเว็บแล้วเลือก QR เพื่อสร้างรหัสที่ชี้ไปยัง URL เว็บไซต์จริง ต้องใช้อินเทอร์เน็ต

เอกสารรายวิชาเป็นต้นแบบ 40 ชั่วโมงต่อปี ให้ปรับตามหลักสูตรสถานศึกษา

ใบงานไฟล์การบ้าน 10 คะแนน; นักสืบโลกออนไลน์และเช็กก่อนแชร์ 6 คะแนน
